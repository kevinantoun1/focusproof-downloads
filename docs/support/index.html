Support

Practical setup and troubleshooting for FocusProof.

Chrome detail

Chrome domain tracking is optional and requires the matching FocusProof extension and native host. If that setup is unavailable, FocusProof still tracks app-level activity, session timing, classifications, away study, History, Insights, Replay, and Receipts.

Sessions

Start a Timer or Open-ended session, pause and resume when needed, confirm Studying Away from Mac when you are working on paper, and review the final timeline before exporting a Receipt.

Backup and restore

Use FocusProof's built-in backup and restore controls. Keep backups in a location you control and verify a restore before deleting the original.

Updating

Use Check for Updates… from FocusProof or Settings. Updates remain under your control and are verified before installation.

Uninstalling

Quit FocusProof, remove the app from Applications, and separately remove the local data folder only if you have exported or backed up anything you want to keep.
