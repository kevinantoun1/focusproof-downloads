# FocusProof 1.0.0

Version 1.0.0 (build 5) · 2026-08-04

FocusProof is a local-first study tracker for macOS. This first public release includes
session-scoped activity tracking, Focused/Distracted/Neutral/Unclassified accounting,
confirmed studying away from the Mac, Session Review, Insights, History, Replay, backups,
and local Receipt exports.

## Independent distribution

FocusProof is distributed independently and is not notarized by Apple. macOS requires manual
approval the first time you open it. Download the DMG, drag FocusProof to Applications, try to
open it, then open **System Settings → Privacy & Security**, choose **Open Anyway** for FocusProof,
and confirm **Open**.

FocusProof does not claim Apple approval, notarization, Developer ID signing, or Gatekeeper
approval. The app remains usable without optional Chrome detail tracking.

## Privacy and data

Session data stays on this Mac. FocusProof records only the activity needed by a running session
under the app's local settings; it does not collect page contents, full URLs, keystrokes,
screenshots, or clipboard contents. Users remain responsible for any data they export, back up,
or share themselves.

## Update channel

Sparkle update checks use HTTPS and EdDSA-signed update archives. Updates remain under the user's
control; no unattended installation is promised.
