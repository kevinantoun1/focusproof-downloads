# FocusProof Downloads

Official public downloads for FocusProof, distributed independently for macOS.

The current release and installation instructions are available at:

https://kevinantoun1.github.io/focusproof-downloads/

FocusProof is distributed independently and is not notarized by Apple. macOS
requires manual approval the first time you open it. Follow the per-app
approval steps on the download page; do not disable Gatekeeper globally.

Optional Chrome domain detail is available through the matching Chrome Web Store
extension and native-host setup. FocusProof remains useful for app-level
tracking, away study, History, Insights, Replay, and Receipts without it.

Existing Chrome Web Store companion (currently labelled Beta; a stable listing
was not claimed in this release):
